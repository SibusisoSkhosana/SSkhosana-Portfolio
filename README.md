# Sibusiso Skhosana - Futuristic Portfolio Website

A premium, cinematic portfolio website built with React, Tailwind CSS, and Framer Motion. Designed to showcase software engineering expertise with a futuristic astronomy-inspired aesthetic.

## 🚀 Features

- **Animated Starfield Background**: Dynamic constellation system with particle effects
- **Hero Section**: Typing animation with smooth scrolling indicators
- **Interactive Skills Galaxy**: Orbiting nodes representing skills and expertise
- **Featured Projects**: Holographic project cards with expandable details
- **Engineering Timeline**: Beautiful animated journey through career milestones
- **Certifications & Learning**: Premium certification cards with rotating indicators
- **Contact Section**: Signal transmission-themed contact form and methods
- **Glassmorphism Design**: Modern glass-effect UI with glowing borders
- **Smooth Animations**: Subtle, professional motion using Framer Motion
- **Responsive Design**: Fully responsive across all devices
- **Dark/Light Mode Toggle**: Space and night mode themes

## 🛠 Tech Stack

- **React 18**: Component-based UI library
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Advanced animation library
- **Vite**: Lightning-fast build tool

## 📋 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd SSkhosana-Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 📝 Customization

To customize for your own portfolio:

1. Update hero text in `Hero.jsx`
2. Modify project details in `Projects.jsx`
3. Update contact info in `Contact.jsx`
4. Change colors in `tailwind.config.js`
5. Update social links throughout
